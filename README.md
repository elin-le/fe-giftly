# Giftly — Frontend

Website thương mại điện tử quà tặng cá nhân hóa (đồ án chuyên ngành).

```bash
npm install
npm run dev        # http://localhost:5173 — mặc định dùng mock API
npm test
npm run build
```

- **Nguyên tắc cho AI/Agent**: [`AGENTS.md`](./AGENTS.md)
- **Trạng thái dự án (tự sinh)**: `PROJECT_SNAPSHOT.md` — chạy `npm run snapshot`
- **Tài liệu**: [`docs/`](./docs) — SRS, use case, kiến trúc, CSDL, API, hướng dẫn cài đặt
